# DesignEverything 8.1.0 — Interactive Question Cards

**Status**: **RELEASE CANDIDATE — awaiting live R-spike**  
**Cut date**: not recorded — live R-spike outstanding  
**Schema**: interview-script 2.1.0

## What shipped

- Claude Code receives native-choice guidance for 14 static catalogs and five grounded
  three-choice hint questions. A user can always select built-in Other or enter free text.
- script.yaml is the single source of truth; AGENTS fallback text is generated from it.
- The core carries an immutable committed-answer snapshot with the prompt capability so hint
  rendering does not infer answers from model memory.
- Codex plugin installation now ships a dedicated text-only skill. It does not claim native cards.

## Compatibility and migration

All fields are additive: scripts without options, recommendation, or option_hints remain
free-text. Copy Design/Adapters/generated/AGENTS.sample.md to a repository-root AGENTS.md
when using a generic rules-only agent. .agents/AGENTS.md is legacy and not a discovery path.

## Evidence, metrics, and limitations

**Provisional — modeled, not yet measured.** The numbers below are a design-time count from the
script structure, not a run through a real Claude Code session. They will be replaced by measured
counts from `Design/RoadMap/evidence/interactive-cards-turn-count-report.md` (B22e) before this
note is cut as GA; do not cite this section as verified evidence until that report exists.

The modeled canonical web journey remains 16 questions: CAL0, S0–S7, R1, S8, W1–W5.
It has 11 assisted questions, 5 free-text questions (S0,S6,R1,S8,W5), 29 card selections
(11 answer, 16 confirmation, 2 critic acknowledgement), 16 successful commits, and at most
16 keyboard-typed submissions in the canonical non-Other/non-timeout journey — down from a
32-message free-text baseline (one message to answer plus one to confirm per question), since
the 5 free-text questions (S0, S6, R1, S8, W5) still require typing both the answer and the
confirmation. This baseline/target pair is the same one used in
[InteractiveQuestionCardsPlan.md](InteractiveQuestionCardsPlan.md) §2 and its status header.

**Known limitations at RC:**
- The R-spike (`UserPromptSubmit` firing on card interaction) has not run in a live session yet;
  B22c currently implements the "commit within the same turn" branch as its working assumption.
  See [r-spike-userpromptsubmit-probe.md](../ContractForAI/Core/v7-expansion/r-spike-userpromptsubmit-probe.md) §7 for the resolved outcome.
- `test/regression/golden-web.test.ts` checks emitted doc structure against fixed answers; it does
  not model card turns. Turn counting lives in a separate journey test (B22e).
- Codex/AGENTS.md receive the same option catalog as text only — no native card surface; see
